Nuke tools

Nuke Heavy Node Optimizer

Artist-facing Nuke Python tool to bulk disable, enable, or toggle user-defined heavy node classes across a script. It is designed to be safe and predictable: it only modifies each node’s disable knob and does not rewire the script.

Focus

Safe node toggling, artist usability, small workflow automation.

Technical notes

Python, Nuke API, PySide2/PySide6 compatibility, JSON configuration, logging, import/export, undo grouping.

Why it matters

Turns a repetitive and error-prone artist habit into a repeatable action with clear boundaries.

Nuke Toolsets

Nuke-integrated Qt browser for reusable disk-based .nk and .py toolsets. It is designed for artists who want to find, insert, create, and manage reusable setups without digging through old scripts.

Focus

Reusable setups, shared/personal libraries, metadata, filtering, and clean handoffs between artists.

Technical notes

Python, Qt/PySide, MVC-style structure, JSON metadata, validation, overwrite confirmations, clear warnings.

Why it matters

Helps organize useful Nuke setups into a workflow artists can browse and trust.
